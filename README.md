# Bookshelf — Client

A modern full-stack **library management application** with role-based access, book management, reviews, events, news, notifications, and an admin messaging system.

## Overview

Bookshelf is a full-stack web application designed to provide a centralized platform for managing library-related content and user interactions.

The application includes separate experiences for **Admin, Member, and Volunteer** users, along with an administrative dashboard for managing the platform.

## Features

* 🔐 Firebase Authentication
* 👥 Role-based user management
* 📚 Book management
* ⭐ Review and rating system
* 📅 Events management
* 📰 News management
* 💬 Admin-to-user messaging
* 📥 Message inbox
* 🔔 Unread notifications
* ✓ Message seen/read status
* 🔎 Search and filtering
* 🖼️ Image upload and preview
* 📜 Conversation auto-scroll
* ⚡ Loading states
* 🔔 SweetAlert feedback
* 📱 Responsive admin interface
* 🌙 Premium dark/gold UI system

## User Roles

The application supports three primary roles:

* **Admin**
* **Member**
* **Volunteer**

Each role can access functionality according to its permissions.

## Messaging System

One of the key features of Bookshelf is its application-style conversation system.

Admins can communicate directly with users through:

* Conversation threads
* Inbox
* Unread message indicators
* Seen/read status
* Conversation continuation
* Automatic conversation scrolling
* Periodic message polling
